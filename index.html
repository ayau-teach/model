📖 Анықтамалар

Бірінші заң

Q = ΔU + A

Q — берілген жылу, ΔU — ішкі энергия өзгерісі, A — газдың жұмысы.

Газдың жұмысы (p = const)

A = pΔV

Жылу қозғалтқышы

A = Q₁ − Q₂   η = (Q₁ − Q₂)/Q₁ · 100%

Q₁ — қыздырғыштан алынған, Q₂ — салқындатқышқа берілген жылу.

Екінші заң

ΔS ≥ 0

Оқшауланған жүйенің энтропиясы кемімейді. Жылу өздігінен ыстықтан суыққа беріледі.
